# SonoGuard · GitHub Pages + Firebase

Aplicación estática de monitoreo de sonido con login de Firebase, roles, analizador de 31 bandas, gráfica de evolución y mapa de lugares con límites de ruido.

**Empieza por [INSTRUCCIONES.md](INSTRUCCIONES.md).**

1. Configura `public/firebase-config.js`.
2. Activa Email/Password y crea tu cuenta administradora.
3. Copia su UID en `public/firebase-config.js` y `firestore.rules`.
4. Crea Cloud Firestore y publica las reglas.
5. Sube este proyecto a GitHub y selecciona GitHub Actions en Settings > Pages.

También incluye `firebase.json` para Firebase Hosting. Esta entrega no está conectada a un proyecto Firebase real y no incluye cuentas ni datos del sitio anterior.
